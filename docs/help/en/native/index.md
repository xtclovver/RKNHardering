# Native signs reference

The detailed reference distinguishes evidence verified by the project from community reports and claims made by external projects. Recommendations are conditional and do not guarantee that a device, VPN, root state, firmware, or server-side signal will be hidden.

## Evidence labels

- **Project verified / проверено проектом / بررسی‌شده توسط پروژه / 项目验证** — implemented and tested in RKNHardering.
- **Community reported / сообщено сообществом / گزارش جامعه / 社区报告** — a user-reported scenario, not a guarantee.
- **External project claim / заявлено внешним проектом / ادعای پروژهٔ بیرونی / 外部项目声明** — a claim that must be audited and tested independently.

Issue [#48](https://github.com/xtclovver/RKNHardering/issues/48) and [RKNHardering-defense](https://github.com/jinndi/RKNHardering-defense) are community reports for TUN, MTU, and IP scenarios. [VPN Hide](https://github.com/okhsunrog/vpnhide) is an external root tool that may itself create root, hook, Zygisk, LSPosed, or vpnhide signals; it does not hide server-side detection, root, or custom firmware. Issue [#51](https://github.com/xtclovver/RKNHardering/issues/51) is retained as discussion context. WINGSV is not recommended because its current documentation does not establish the protection mechanism required by these vectors.
