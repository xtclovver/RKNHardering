# مقایسهٔ IP

## چه چیزی و چرا بررسی می‌شود

ماژول توافق درون گروه‌های RU و non-RU را می‌سنجد و سپس IP عمومی معیار آن‌ها را برای یافتن تفاوت مسیر مقایسه می‌کند.

## نتیجه چه معنایی دارد

اختلاف می‌تواند از split tunneling، VPN/پروکسی، خطای سرویس، تفاوت IPv4/IPv6 یا تغییر شبکه باشد و علت مشخصی را ثابت نمی‌کند.

## محدودیت‌ها و مثبت کاذب احتمالی

خطای موقت سرویس، captive portal و جابه‌جایی شبکه می‌تواند توافق را موقتاً خراب کند. آزمون را روی شبکهٔ پایدار تکرار کنید.

## توصیه‌های همین بردار

پروژهٔ بیرونی [gowarp-server](https://github.com/paulkarpunin/gowarp-server) راه‌اندازی WARP روی سرور Linux دارای root را ادعا می‌کند؛ این تضمین بررسی‌شده نیست. curl-to-bash را اجرا نکنید. اسکریپت را ممیزی کنید، firewall و مسیرها را بررسی کنید، پشتیبان بگیرید و ابتدا روی VPS آزمایشی با مسیر بازیابی روشن امتحان کنید.

## مجوزهای لازم و خطرها

خود بررسی از دسترسی شبکهٔ موجود استفاده می‌کند. تغییر WARP/VPS به root سرور نیاز دارد و خطای مسیر یا firewall می‌تواند دسترسی را قطع کند. این روش نشانه‌های بومی، روت دستگاه، رام سفارشی یا تشخیص سمت سرور را پنهان نمی‌کند.

## سطح شواهد

**بررسی‌شده توسط پروژه:** منطق توافق و مقایسه در RKNHardering پیاده‌سازی و آزموده شده است. **ادعای پروژهٔ بیرونی:** سناریوی WARP/VPS مشروط است.
