# مرجع RKNHardering

این مرجع تفصیلی، واقعیت‌های بررسی‌شده در پروژه را از گزارش‌های جامعه و ادعاهای پروژه‌های بیرونی جدا می‌کند. توصیه‌ها به دستگاه وابسته‌اند و پنهان‌شدن VPN، دسترسی روت، تغییرات firmware یا نشانگرهای سمت سرور را تضمین نمی‌کنند.
