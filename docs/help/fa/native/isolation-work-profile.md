# سیگنال بومی: isolation-work-profile

## چه چیزی و چرا بررسی می‌شود

RKNHardering بردار پایدار `isolation-work-profile` را از وضعیت Android و لایهٔ بومی که برای برنامه قابل مشاهده است بررسی می‌کند.

## نتیجه چه معنایی دارد

نتیجهٔ review یعنی اثری برای مقایسه با پیکربندی دستگاه دیده شده است؛ این حکم مستقل نیست.

## محدودیت‌ها و مثبت کاذب احتمالی

رام سازنده، مدیریت سازمانی، شبیه‌ساز، profile و ابزار توسعه می‌تواند وضعیت مشابه بسازد.

## توصیه‌های همین بردار

پیش از غیرفعال‌کردن clone، کاربر دوم، نمایهٔ کاری یا جداسازی سازنده، عمدی‌بودن آن را بررسی کنید.

## مجوزهای لازم و خطرها

خود بررسی مجوز اضافه نمی‌خواهد. تغییرات روت، رام، mount، property یا profile خطر boot-loop، از دست‌رفتن داده و تضعیف جداسازی دارد؛ ابتدا پشتیبان بگیرید.
