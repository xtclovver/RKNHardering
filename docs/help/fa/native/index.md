# راهنمای نشانه‌های بومی

این راهنما شواهد بررسی‌شده توسط پروژه را از گزارش‌های جامعه و ادعاهای پروژه‌های بیرونی جدا می‌کند. توصیه‌ها وابسته به دستگاه‌اند و پنهان‌شدن VPN، روت، رام یا نشانه‌های سمت سرور را تضمین نمی‌کنند.

## برچسب‌های شواهد

- **بررسی‌شده توسط پروژه** — بردار در RKNHardering پیاده‌سازی و آزموده شده است.
- **گزارش‌شده توسط جامعه** — سناریوی کاربر است، نه تضمین.
- **ادعای پروژهٔ بیرونی** — ادعا باید مستقل ممیزی و آزمایش شود.

Issue [#48](https://github.com/xtclovver/RKNHardering/issues/48) و [RKNHardering-defense](https://github.com/jinndi/RKNHardering-defense) گزارش‌های جامعه دربارهٔ TUN، MTU و IP هستند. [VPN Hide](https://github.com/okhsunrog/vpnhide) ابزار روت بیرونی است و ممکن است خودش سیگنال‌های root، hook، Zygisk، LSPosed یا vpnhide بسازد؛ تشخیص سمت سرور، روت یا رام سفارشی را پنهان نمی‌کند. Issue [#51](https://github.com/xtclovver/RKNHardering/issues/51) فقط به‌عنوان زمینهٔ بحث نگه داشته شده است. WINGSV توصیه نمی‌شود، چون مستندات کنونی سازوکار حفاظتی لازم را ثابت نمی‌کند.
