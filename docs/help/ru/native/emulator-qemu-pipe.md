# Нативный сигнал: emulator-qemu-pipe

## Что проверяется и зачем

RKNHardering проверяет стабильный нативный вектор `emulator-qemu-pipe` по доступному приложению состоянию Android и native-слоя.

## Что означает результат

Review означает, что вектор показал артефакт для сверки с конфигурацией устройства. Это вспомогательное доказательство, а не самостоятельный вердикт.

## Ограничения и возможные ложные срабатывания

Прошивка производителя, корпоративное управление, эмуляторы, профили и легитимные инструменты разработки могут давать похожее состояние.

## Рекомендации для этого вектора

Сверьте значение эмулятора или build-профиля с реальным устройством и чистой сборкой. Не переписывайте build properties без способа восстановления.

## Необходимые права и риски

Дополнительные разрешения для проверки не нужны. Привилегированные изменения root, прошивки, mount, свойств или профилей могут вызвать boot-loop, потерю данных или ослабление изоляции; сначала backup.

## Уровень доказательности

**Проверено проектом:** вектор реализован и покрыт checker/catalog-тестами. Внешние заявления о скрытии остаются условными.
